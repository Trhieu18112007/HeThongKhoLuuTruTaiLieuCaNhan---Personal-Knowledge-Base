# wireframe.md - Phác thảo giao diện (ASCII)

> Chép từ `PLAN.md` mục 4 và 5 để đạt Milestone 1. Hiền và Tài sẽ bổ sung ảnh vẽ tay/Figma (`docs/wireframe-*.png`).

## Sơ đồ trang

```
                 +---------------------------+
                 |  index.html (Trang chủ)   |
                 +---------------------------+
                   |          |            |
            (search)     (card click)   (nút "Thêm")
                   v          v            v
         +----------------+  +-----------------+  +--------------+
         | library.html   |->| detail.html?id= |  |  add.html    |
         | (Kho tài liệu) |  | (Chi tiết+Note) |  | (Thêm tài    |
         +----------------+  +-----------------+  |  liệu: form) |
                  ^                  |            +--------------+
                  +------ quay lại --+                    |
                  ^---------------------------------------+ (lưu xong về library)
```
